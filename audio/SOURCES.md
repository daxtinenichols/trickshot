# Audio sources and licences

Every sound in `audio/` is synthesised at runtime by code written for this project, except the voice lines, which are generated offline by an Apache-2.0 speech model (below). There are no recordings, samples or third-party audio files.

| Sound | Made by | Licence |
|---|---|---|
| Footsteps, landings, debris, jumps, hand plants, whooshes, rolls, bonks, kicks (`sound_bank.gd`) | Synthesised in code (sines, filtered noise, decaying partials) | Ours, same as the repo |
| Slide scrape, wind loops, radio crackle (`sound_bank.gd`) | Synthesised in code | Ours |
| Doors, glass, combo chimes, bail sting, radio jingles, slow-mo sweeps (`sound_bank.gd`) | Synthesised in code | Ours |
| Music: pad, drums, bass, percussion, lead (`music_synth.gd`) | Composed and synthesised in code (E minor, 124 BPM) | Ours |

| Radio voices and raider taunts (`voices/tts/`) | Generated by `tools/make_voices.py` with [Kokoro-82M](https://github.com/hexgrad/kokoro) v1.0 (voices am_fenrir, bf_emma, af_heart, am_michael, af_kore, am_puck, bm_lewis), run via [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) | Model and voices Apache-2.0, which allows shipping the generated audio commercially; the lines are ours |
| Recorded voice takes (`voices/recorded/`, none yet) | Recorded by us | Ours |

The gun's sounds are the art thread's (`art/fx/gun_audio.gd`), also synthesised.

If a recorded or downloaded sound is ever added, it must be CC0 or made by us, and gets a row here with its source URL and licence.
